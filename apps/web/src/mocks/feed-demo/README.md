# Datos de ejemplo del feed

Fotos y trazados usados solo por el modo de vista previa de desarrollo (`pnpm dev` con `?vista-previa`) y por las capturas de Android en pruebas. No se incluyen en el build de produccion: el modulo se importa de forma dinamica detras de `import.meta.env.DEV`.

Las fotos se recortaron a 480x360 y se comprimieron en JPEG. Los corredores, textos y comentarios son ficticios.
